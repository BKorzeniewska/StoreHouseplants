# StoreWithHouseplants
**About**
This application was developed as my bachelor’s engineering project. It is built with a back-end in Spring (Java) and a front-end in React (TypeScript).
The goal is to provide a simple and user-friendly platform for managing and browsing indoor houseplants, their categories, care instructions and inventory.

Please note that this project does not fully follow clean code principles.
It was created for learning purposes and should not be treated as a representation of my current coding style or professional work.

##Features
Browse a catalogue of indoor plants with photos, descriptions and care tips.
Filter and search plants by category, light requirements, size, and other attributes.
Admin panel for adding, editing and removing plant entries (for project demonstration purposes).
Responsive front-end so the site works on both desktop and mobile devices.
REST API built with Spring that handles plant data, users and categories.
React front‐end communicates with the API and provides a seamless user experience.
